The Studio can arrive without replacing the Compiler

Current: Compiler Core
The first version is intentionally file-driven, source-controlled, and deterministic. It operates without:
Standing AI API costs
Opaque autonomous publishing paths
Client database requirements
Future: AURA Studio
A future Studio adds a friendly interface over the exact same contracts:
Discovery portal & Evidence approval desk
Strategy board & Photo review board
Content review & Release dashboard
The core principle remains unchanged
The interface may become easier, but it must never bypass the evidence, strategy, asset, and release gates established by the Compiler.
