AI drafts inside evidence boundaries

Prompt Packets
The prompt compiler produces reviewable packets. Each packet strictly defines the boundaries for AI generation, including:
  • Selected architecture and page role
  • Allowed claim IDs
  • Prohibited assertions
  • Visual direction and output contract
  • Approval state
The Compose Step
The compose step does not fill a missing source fact with plausible language. It emits an explicit [NEEDS APPROVAL] placeholder.

A claim can only be used publicly when its evidence register records:
  • Source and permission
  • Timeframe and scope
  • Caveat and allowed placement
This is why AURA can use AI for structured acceleration without reducing a premium website to untraceable marketing output.
