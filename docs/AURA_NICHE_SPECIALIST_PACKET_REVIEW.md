# Niche Specialist: AI Prompt and Photographer Packet Review

## Purpose

The Niche Specialist pack is designed for a specialist whose commercial value comes from **specific diagnosis**, not broad personal authority or event-booking charisma. The visual system therefore has to make operational judgment visible without inventing dashboards, client access, project outcomes, or technical proof.

> Every packet begins with the approved architecture, visual world, image strategy, consent state, placement, and crop requirement. The image maker is given a defined job, not a vague instruction to create a “professional consultant photo.”

The Dr. Marcus Hill pack uses the concept visual world **Operational Fieldwork**: deep ink, mineral white, restrained signal lime, documented working scenes, and a quiet technical editorial treatment. The present pack has `synthetic_concept` status; it cannot inherit the identity or client context of a real person.

## Prompt anatomy

The generated packet is deliberately composed of four layers.

| Layer | What it controls | Why it matters for the Niche Specialist archetype |
|---|---|---|
| **Approved context** | Architecture, visual world, image strategy, consent state, placements and aspect ratios. | A method artifact cannot be repurposed as a hero, and a synthetic concept cannot be published as evidence. |
| **Visual job** | The single cognitive task of the image. | The hero creates diagnostic specificity; the artifact makes the method inspectable; the working scene suggests disciplined fieldwork; the conversation image supports qualified conversion. |
| **Generation prompt** | Subject/location chapters, composition, material treatment and prohibited artifacts. | The model is directed away from dashboards, invented metrics, logos, stock poses, readable text, and fabricated work. |
| **Photographer alternative + QA** | Capture requirements plus consent/provenance, crop, face/hand/edge/text and alt-text checks. | AI-generated concepts and real photography follow one approval system, so the production handoff does not change quality standards. |

## Concrete prompt controls

The hero packet requires a **cinematic subject placement with a copy-safe negative-space zone**. It asks for a capable, composed, specific person rather than an aspirational stock subject. Its explicit prohibitions include visible logos, readable invented text, fabricated media, fake client work, fake event context, plastic skin, malformed hands, and unrelated lifestyle props.

The method-artifact packet changes the request entirely. It calls for a **material process artifact or document detail** and specifically says not to generate invented readable text, fake reports, or fabricated brand marks. This distinction is central: a diagnostic site should not dress an image of a whiteboard up as operational evidence.

Every image packet requires the following release gate before publication:

1. Consent and provenance match the client pack.
2. Face, hands, jewelry, edges and text artifacts have been inspected.
3. The stated desktop and mobile crops preserve the visual job.
4. Final alt text is supplied, unless the image is genuinely decorative.

## How this differs from the other archetypes

| Archetype | Core visual proof job | Image risk that the Compiler blocks |
|---|---|---|
| **Private Signal** | Discretion, considered presence, proprietary method and a trusted private room. | Pretending that private access, board work or confidential outcomes are public proof. |
| **Authority + Speaking** | Event-buyer relevance, stage context, rehearsal, and bookable topic fit. | Treating an unverified stage image or crowd as an actual speaking credential. |
| **Niche Specialist** | Diagnostic precision, material method, real operating context and an assessment-ready relationship. | Presenting abstract arrows, fake screens, or an AI conversation as client evidence. |

## Generated asset review

The concept preview implements all four planned roles. The hero serves P02; the physical decision-flow map serves P09; the glass-board working scene serves P05; and the private conversation context serves P08. Every live preview section includes a visible concept-safe disclosure, and the assessment form is non-collecting.

The package is fit for **creative review and approved photographer briefing**. Before a live client release, the unresolved wardrobe/location placeholders, identity consent state, approved source assets, alt text, and claim-to-evidence links must be completed in the client pack.
